# 시스템 구조

| 계층 | 위치 | 책임 |
| --- | --- | --- |
| 화면 | `frontend/src/` | React로 화면을 렌더링하고 사용자 입력을 처리합니다. 화면이 늘어나면 React Router를 도입합니다. |
| API | `backend/app/` | FastAPI로 HTTP 요청을 받고 Pydantic으로 API 데이터 형식을 정의합니다. 현재는 헬스 체크만 제공합니다. |
| 비즈니스 로직 | 기능 도입 시 구성 | 추천과 일정 등 도메인 규칙을 처리합니다. |
| 데이터 접근 | 기능 도입 시 구성 | 애플리케이션의 저장 및 조회를 담당합니다. Firebase 연동 설정과 Firestore 규칙은 `firebase/`에서 관리합니다. |

화면과 API는 각각 실행할 수 있습니다. 서비스 기능이 생기면 API 처리, 비즈니스 규칙, 데이터 접근을 별도 모듈로 분리합니다.
